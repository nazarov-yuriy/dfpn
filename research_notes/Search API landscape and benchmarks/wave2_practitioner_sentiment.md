# Wave 2 — Practitioner sentiment on search APIs in real agent workloads (as of 2026-11-05)

Scope: what practitioners, journalists and vendor status/issue trackers say about Exa, Tavily, Brave, Perplexity, Parallel, Keenable, Linkup, Firecrawl, Jina, SerpApi and Serper in production agent use. HN launch threads were excluded (covered by another researcher).

Source-access caveats for this wave (important for the report writer):
- Reddit was unreachable from this session by every route tried: old.reddit.com (WebFetch refused), reddit.com via WebSearch (`400: domains not accessible to our user agent`), DuckDuckGo HTML fallback (returned a bot-verification CAPTCHA twice), Bing fallback (ignored the `site:reddit.com` operator and returned Brave-browser pages), and raw curl of old.reddit.com (HTTP 403 "blocked due to a network policy", 2026-11-05). No Reddit quotes could be collected.
- xcancel.com returned HTTP 451 (Unavailable For Legal Reasons), so no X posts were collected.
- status.search.brave.com did not resolve from this session (host not in allowed network domains), so Brave's incident history is missing.
- Labels used below: **vendor** = the company selling the API or a competitor; **independent** = third-party benchmark/analyst site; **journalist** = press; **practitioner** = individual developer/newsletter/npm author or GitHub issue filer.

## Q1. Exa's reported weaknesses on exact-match / keyword queries, and pricing complaints

### Takeaway
Three separate practitioner/independent sources (Mar–Jul 2026) converge on the same weakness: Exa's neural retrieval is unreliable for narrow, keyword-exact or code-specific lookups, where keyword engines do better; the pricing complaints that surfaced are less about headline per-query price than about hard 429s at quota, a separate Websets product ($49–$449+/mo), and conflicting published per-1k rates ($2.50 vs $5–$15).

### Cited Findings
- **Keyword/technical queries (practitioner-rating site, Rhumb AN Score, scorecard dated 2026-03-30, updated 2026-06-01; dev.to repost undated):** "Neural/semantic search can behave unpredictably on highly specific technical queries — traditional keyword search sometimes returns more reliable results for code-related lookups"; also "`highlights` field (extracted key passages) is powerful but not always accurate; agents should treat it as a hint, not ground truth." — [dev.to/supertrained (Rhumb)](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g); scorecard dates from [rhumb.dev](https://rhumb.dev/blog/exa-vs-tavily-vs-serper-vs-brave-search)
- **Quota behaviour (same source, practitioner):** "Free tier is generous but rate limits drop hard at quota: no graceful degradation, just 429s" — yet the same article says the 429 comes "with a Retry-After header" so agents "can backoff and resume." — [dev.to/supertrained](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g)
- **Simple factual lookups (practitioner, Deepak Gupta, 2026-07-30):** Exa is a "poor fit for simple factual lookups where keyword matching already works"; author also flags that Exa's developer docs contain text addressed to AI coding agents and treats this as a prompt-injection risk. — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/)
- **Keyword-relevance mini-benchmark (practitioner, pi-search-multi npm package, report dated 2026-05-04):** on 3 queries x 5 results scored by keyword relevance/diversity/snippet completeness, Exa was fastest (137 ms avg) but scored 3.2/10, below Tavily (3.7), Serper/Firecrawl/DuckDuckGo (3.5) and Brave (3.3); for the query "latest AI frameworks 2025" Exa's sample top hit was "Monarch: an API to your supercomputer – PyTorch". — [pi-search-multi benchmark-report.md](https://cdn.jsdelivr.net/npm/pi-search-multi@1.0.1/benchmark/benchmark-report.md)
- **Independent agent benchmark (AIMultiple, updated 2026-05-13/14):** Exa ranked 3rd of 8 with Agent Score 14.39 (95% CI 13.25–15.50), latency ~1.2 s; top four "perform equally well". — [aimultiple.com/agentic-search](https://aimultiple.com/agentic-search)
- **Pricing figures conflict across sources:** journalist (Implicator.ai, 2026-06-08) lists Exa at "$2.50 per 1,000" — [implicator.ai](https://www.implicator.ai/brave-drops-free-search-api-tier-puts-all-developers-on-metered-billing/); independent (AIMultiple, May 2026) lists "Pay-as-you-go at $5–$15 per 1k requests/pages" and Websets at $49/$449/custom — [aimultiple.com](https://aimultiple.com/agentic-search); practitioner (Gupta, 2026-07-30) lists Websets as "a separate product at $49 to $449+ per month" among "pricing surprises". — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/)
- **Positive practitioner view (newsletter, Agent Native Registry, 2026-03-06):** Exa scored 88/100, "The only search API with both an MCP server and agent-native account creation"; "Free tier: 1,000 searches/month"; gap: "no llms.txt". — [buttondown.com/agentnative](https://buttondown.com/agentnative/archive/we-scored-5-search-apis-for-ai-agents-2-were)
- **Recurring problems in Exa's MCP repo (practitioner issue filers, exa-labs/exa-mcp-server, 131 issues total as of 2026-11-05):** #475 "web_search_exa request timed out after 300 seconds" (open, 2026-11-03); #470 "A null or empty optional number is coerced to 0, so maxAgeHours: null forces live crawling" (open, 2026-11-01); #446 "mcp.exa.ai and api.exa.ai both return Cloudflare 403 from datacenter IP" (closed 2026-10-07, title notes the self-hosting workaround from #414 did not work); #458 "Proposal: Mark search and fetch results as untrusted web content" (open, 2026-10-13). — [github.com/exa-labs/exa-mcp-server/issues](https://github.com/exa-labs/exa-mcp-server/issues?q=is%3Aissue)
- **Vendor-run benchmark (Exa, runs 2026-07-29 to 2026-08-02):** Exa's own comparison page says "Brave is the strongest general web index we tested, while Exa leads on entity retrieval and groundedness"; groundedness table Exa 79.4, Brave 76.3, Parallel 75.3, Perplexity 64.6, Tavily 61.1; query sets and grading code at github.com/exa-labs/benchmarks. — [exa.ai/versus/brave](https://exa.ai/versus/brave) (vendor); [exa-labs/benchmarks](https://github.com/exa-labs/benchmarks) (vendor)
- **Vendor-run cross-benchmark (Perplexity search_evals README, fetched 2026-11-05):** Exa Agent API scored lowest of five harnesses on all four suites: dsqa 0.53, browsecomp 0.38, hle 0.387, widesearch 0.471 (vs Perplexity 0.871/0.805/0.612/0.651). — [github.com/perplexityai/search_evals](https://github.com/perplexityai/search_evals) (vendor; competitor-run)

### Inferences
- The "exact-match weakness" is well attested qualitatively but no source quantifies it with a keyword-only query set; the pi-search-multi report is the only reproducible artefact showing Exa underperforming on keyword relevance, and it is tiny (3 queries).
- Exa's own framing ("Brave is the strongest general web index we tested") implicitly concedes the general-web/keyword gap while reframing its strength as entity retrieval/groundedness.
- Billing surprises for Exa appear to come from product structure (Websets, live-crawl vs cached content as in issue #470) rather than from the headline search price.

### Gaps
- No Reddit or X complaints about Exa pricing or keyword queries could be retrieved (access blocked); the task's premise of "pricing complaints" rests only on the sources above.
- The $2.50 vs $5–$15 per-1k discrepancy was not resolved against Exa's pricing page (not fetched this wave).

## Q2. Reaction to Brave's free-tier removal

### Takeaway
Brave removed its genuinely free Search API tier in February 2026 (2,000 q/mo in 2023, 5,000 q/mo "Free AI" plan from Aug 2025) and replaced it with four paid plans carrying $5/month in credits (~1,000 searches) that require public attribution and a chargeable card with no listed spending cap; the only documented developer backlash located is a ~35-comment GitHub issue closed "NOT_PLANNED" (reported by a journalist; not located directly) — Reddit/X reactions could not be retrieved.

### Cited Findings
- **Timing and terms (journalist, Marcus Schuler, Implicator.ai, 2026-06-08):** "Brave removed the free tier in February 2026." Original 2023 free tier: 2,000 queries/month at 1 request/second with a hard cap. August 2025: "Free AI" plan of 5,000 queries/month with AI-use rights; a free "Data for Search" plan whose terms "prohibit using responses for AI inference." Current: four paid plans each with $5 monthly credits — Search $5 per 1,000 requests (~1,000 queries from credit); Answers $4 per 1,000 queries plus $5 per million tokens; Spellcheck and Autosuggest $5 per 10,000 requests each. — [implicator.ai](https://www.implicator.ai/brave-drops-free-search-api-tier-puts-all-developers-on-metered-billing/)
- **Attribution and card requirement (journalist quoting Brave, 2026-06-08):** Brave blog: "all you need to do is attribute the Brave Search API in your project's website / about pages"; Brave FAQ: "The credit card requirement serves as an anti-fraud measure to protect Brave from bad actors who want to abuse our API" and "For free plans, the card is only used to confirm your identity and will not be charged." The article says the pricing page lists no spending cap and that users reported a card "already been added" while the dashboard showed "no subscription". — [implicator.ai](https://www.implicator.ai/brave-drops-free-search-api-tier-puts-all-developers-on-metered-billing/)
- **Brave's own earlier positioning, contrasted by the journalist (2026-06-08):** Brave's comparison guide (last updated Oct 2025) promised "a generous free tier for testing and other projects" and "without dependencies or sudden price hikes, unlike many competitors." — [implicator.ai](https://www.implicator.ai/brave-drops-free-search-api-tier-puts-all-developers-on-metered-billing/)
- **Developer backlash evidence (journalist, 2026-06-08):** "A GitHub issue on the official MCP servers repository drew 35 comments. The issue was closed as 'NOT_PLANNED'." A moderator reportedly gave a user the address searchapi-support@brave.com. The article contains no verbatim developer quotes and links no Reddit/X threads. — [implicator.ai](https://www.implicator.ai/brave-drops-free-search-api-tier-puts-all-developers-on-metered-billing/). A search of `modelcontextprotocol/servers` issues for "brave search free tier credit card" returned 0 results on 2026-11-05 — [github.com/modelcontextprotocol/servers/issues](https://github.com/modelcontextprotocol/servers/issues?q=brave%20search%20free%20tier%20credit%20card)
- **Competitor pricing the journalist used as contrast (2026-06-08):** Exa $2.50/1k; Tavily $8/1k; Kagi $25/1k ("five times Brave's price"); Serper 2,500 free monthly searches. — [implicator.ai](https://www.implicator.ai/brave-drops-free-search-api-tier-puts-all-developers-on-metered-billing/)
- **Independent benchmark confirms post-change pricing (AIMultiple, May 2026):** "Search plan at $5 per 1,000 requests, with $5 in monthly free credits. Answers plan at $4 per 1,000 requests plus token fees." — [aimultiple.com/agentic-search](https://aimultiple.com/agentic-search)
- **Rate-limit constraint (practitioner, Gupta, 2026-07-30):** Brave Answers plan "capped at 2 requests per second on standard plans" — "a real constraint for high-throughput agents"; zero data retention only on Enterprise. — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/)
- **Brave quality standing despite the change (independent, AIMultiple, May 2026):** Brave ranked #1 of 8 (Agent Score 14.89, CI 13.80–15.93) with lowest latency 669 ms; "Brave was the only API to reliably outperform Tavily". — [aimultiple.com/agentic-search](https://aimultiple.com/agentic-search). Practitioner (Rhumb, Mar 2026) gives the counter-view: Brave 7.1/10, "Index coverage is smaller than Google/Bing — some niche technical queries return sparse results"; "Rate limit documentation is less precise than Exa/Tavily; agents need more defensive retry logic." — [dev.to/supertrained](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g)
- **Practitioner mini-benchmark note (pi-search-multi, 2026-05-04):** "Brave Search — 460ms avg, 3.3/10 quality (fast, ~1 req/s limit)". — [pi-search-multi report](https://cdn.jsdelivr.net/npm/pi-search-multi@1.0.1/benchmark/benchmark-report.md)
- **Alternatives content spawned by the change:** Firecrawl published "Brave Search API alternatives" (vendor) — [firecrawl.vercel.app/blog/brave-search-api-alternatives](https://firecrawl.vercel.app/blog/brave-search-api-alternatives); agentdeals.dev lists "Best Brave Search API Alternatives with Free Tiers (2026)" and logged the change in its Feb 9–15, 2026 pricing digest (aggregator) — [agentdeals.dev/digest/2026-w07](https://agentdeals.dev/digest/2026-w07), [agentdeals.dev/alternative-to/brave-search-api](https://agentdeals.dev/alternative-to/brave-search-api)

### Inferences
- The February 2026 change coincided with the Bing Search API shutdown, leaving Brave one of few independent indexes; its benchmark lead (AIMultiple #1) gives it pricing power, which is consistent with dropping the free tier.
- The practical complaint is less the $5/1k price (competitive) than the combination of card-on-file with no spending cap plus mandatory attribution to earn the credit.

### Gaps
- No verbatim developer reactions (Reddit, X, GitHub) were retrievable; the 35-comment GitHub issue could not be located by search and should be found via `is:closed` in `modelcontextprotocol/servers` or in `brave/brave-search-mcp-server`.
- A search snippet attributed to "a Brave team member" the clarification that existing free-plan subscribers were unaffected; the primary source for that statement was not identified and should be treated as unverified.
- Brave's status/incident history is unavailable (status.search.brave.com unresolvable from this session).

## Q3. Tavily reliability and the "SERP-based" accusation

### Takeaway
Tavily's status page shows 100% uptime Aug–Nov 2026 with no incidents, and practitioner benchmarks rate it high on extraction and speed, but independent AIMultiple places it 5th of 8 (the only statistically robust gap in that study is Brave beating Tavily); the closest published support for the "SERP wrapper" accusation is Rhumb's note that Tavily relies on "multiple search backends" with no way to verify which backend answered — no source found states outright that Tavily resells Google SERP.

### Cited Findings
- **Status page (vendor, fetched 2026-11-05):** "We're fully operational"; Aug 2026–Nov 2026 uptime: Tavily API Service 100%, Tavily MCP 100%, Tavily Website 100%; no incidents listed. — [status.tavily.com](https://status.tavily.com/)
- **Backend opacity (practitioner-rating, Rhumb, 2026-03-30/2026-06-01):** "Underlying results rely on multiple search backends, so result ordering can shift between API versions"; "No way to force a specific search engine or verify which backend was used for a given query — opacity matters when debugging agent hallucinations"; "`answer` synthesis is often good but shouldn't be used as ground truth". Score 8.6/10, second to Exa 8.7. — [dev.to/supertrained](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g)
- **Credit multipliers (practitioner, Rhumb, Mar 2026 and Gupta, 2026-07-30):** "`search_depth: "advanced"` mode costs 2x the credits ... An agent that can't reason about which mode to use will either overspend on credits or return shallow results" — [dev.to/supertrained](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g); Gupta: advanced search 2 credits, "deep research costs 15 to 250 credits per call"; Tavily plans: Researcher free 1,000 credits/mo, Project $30/mo, PAYG $0.008/credit; Nebius acquisition "reported $275M (up to $400M on milestones)". — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/), pricing also in [aimultiple.com](https://aimultiple.com/agentic-search)
- **Independent benchmark (AIMultiple, May 2026):** Tavily 5th of 8, Agent Score 13.67 (CI 12.62–14.76), latency 998 ms; Brave-vs-Tavily "about 1 point" gap "held up across repeated statistical tests" (paired bootstrap, 10,000 resamples); Tavily quality/relevance "marginally lower" than top tier. — [aimultiple.com/agentic-search](https://aimultiple.com/agentic-search)
- **Practitioner mini-benchmark (pi-search-multi, 2026-05-04):** Tavily "Best quality" 3.7/10, 356 ms avg, 100% success; recommended first "with API key" for "rich content extraction". — [pi-search-multi report](https://cdn.jsdelivr.net/npm/pi-search-multi@1.0.1/benchmark/benchmark-report.md)
- **Practitioner vendor-selection model (Alyshia Ledlie, 2026-04-06):** Tavily weighted score 69 vs Brave 72, Firecrawl 71, open-source stack 74; "Research or extraction-heavy agent (maximize content coverage) → Firecrawl or Tavily favored". — [aledlie.vercel.app](https://aledlie.vercel.app/reports/2026/llm-native-search-evaluation/)
- **Newsletter (Agent Native Registry, 2026-03-06):** Tavily 87/100; "Used in LangChain and AutoGPT integrations — which means the library of examples is already there"; gap "no llms.txt". — [buttondown.com/agentnative](https://buttondown.com/agentnative/archive/we-scored-5-search-apis-for-ai-agents-2-were)
- **Recurring issues in tavily-ai/tavily-mcp (practitioner filers; 73 issues total, fetched 2026-11-05):** #211 "tavily_search returns isError: false on 401 auth failure" (open, 2026-09-05); #204 "extract returns empty Detailed Results for SPA docs sites" (closed 2026-10-10); #238 "tavily_extract drops failed_results from formatted responses" (open, 2026-10-29); #184 "API key passed via GET URL parameter (security concern)" (open, 2026-07-06); #187 "tavily_search returns HTTP 400 behind an HTTP proxy" (open, 2026-07-14); #161 "Missing API key throws McpError instead of returning isError: true" (open, 2026-04-29). No rate-limit, outage or billing issues visible on page 1. — [github.com/tavily-ai/tavily-mcp/issues](https://github.com/tavily-ai/tavily-mcp/issues?q=is%3Aissue)
- **Vendor-run competitor benchmarks place Tavily last on groundedness:** Exa's table: Tavily 61.1 vs Exa 79.4 (runs 2026-07-29 to 08-02). — [exa.ai/versus/brave](https://exa.ai/versus/brave) (vendor)
- **Vendor self-description (Tavily docs, undated):** "We take care of all the burden of searching, scraping, filtering and extracting the most relevant information from online sources. All in a single API call!" — [docs.tavily.com/documentation/about](https://docs.tavily.com/documentation/about)
- **Review-site user comments (secondary, from search summary; URL not individually verified):** a reviewer said "the pricing structure feels a bit steep once you scale past the initial hobbyist phase"; another moved from Serper because "Tavily's extraction is just more robust for our specific use case involving deep financial research". — [tooliverse.ai/tools/tavily](https://tooliverse.ai/tools/tavily) / [aitoolsatlas.ai](https://aitoolsatlas.ai/tools/tavily/review)

### Inferences
- The "SERP-based" accusation is unproven in sources found this wave; what is documented is multi-backend aggregation with no provenance field, which is what makes the accusation hard to refute or confirm from the outside.
- Tavily's reliability complaints cluster around MCP-layer error semantics (401 reported as success, failed results silently dropped) rather than API downtime.

### Gaps
- No Reddit/X thread making or rebutting the SERP accusation was retrievable.
- Tavily's status page history beyond Aug 2026 was not fetched; whether earlier incidents exist is unknown.

## Q4. Keenable early-user reports

### Takeaway
As of 2026-11-05 no practitioner reviews of Keenable were found anywhere accessible (directory sites show zero ratings); all numbers come from Keenable itself, press coverage of its $26M seed, Artificial Analysis's Search Index (via a competitor's write-up), and Parallel's competitor comparison, which lists $4/1k self-serve pricing, a recurring 100,000-request free allowance, 10 rps/org rate limit and no SOC 2 attestation as of 2026-10-21.

### Cited Findings
- **Pricing/limits as read by a competitor (vendor: Parallel, undated page citing 2026-10-19 and 2026-10-21 data):** "$4 per 1,000; $1 per 1,000 only at 100+ rps dedicated"; free allowance "100,000 requests/month, recurring"; rate limits "10 rps per org; 1,000 req/hour per IP keyless"; "No SOC 2 or other attestation as of Oct 21, 2026". Parallel's own: Turbo/Fast $1/1k, Basic/Advanced $5/1k, SOC 2 Type 2. Cost crossover computed by Parallel at ~132,000 requests/month. — [parallel.ai/articles/keenable-vs-parallel.md](https://parallel.ai/articles/keenable-vs-parallel.md)
- **Third-party benchmark numbers relayed by Parallel (independent: Artificial Analysis Search Index, published 2026-10-19, runs mid-Aug 2026):** Keenable AA Index score 67 (both modes); avg search-call latency 0.34 s realtime / 1.11 s pro; BrowseComp (pro) 65.5%. Parallel Advanced 75, Fast 73, Turbo 67; Parallel Fast BrowseComp 71.5%. Caveat from the page: AA runs predate Keenable's "dynamic snippets" change. — [parallel.ai/articles/keenable-vs-parallel.md](https://parallel.ai/articles/keenable-vs-parallel.md)
- **Keenable-run benchmark (vendor, relayed by competitor):** NEEDLE pooled score Keenable 74% vs Exa and Brave 67%, Parallel Basic 61%, Turbo 53% (Oct 19 results); Parallel notes "the LLM judge lacks a human-agreement audit" and that NEEDLE grades top-five ranking, not answer accuracy. Keenable reports BrowseComp 56.6% → 67.3% after dynamic snippets, which "roughly halved production response size". — [parallel.ai/articles/keenable-vs-parallel.md](https://parallel.ai/articles/keenable-vs-parallel.md)
- **Vendor claims via press (journalist, 36kr, 2026):** query latency below 250 ms (p95) in US East; developer pricing ~$4 per 1,000 requests, ~$1 at 100+ RPS dedicated; index >100 billion documents. — [eu.36kr.com](https://eu.36kr.com/zh/p/3972565139845640)
- **Funding (journalist, secondary relays of TechCrunch):** $26M seed led by Accel, 15 engineers, founders ex-Yandex/Amazon. — [aiunderstanding.org](https://aiunderstanding.org/news/techcrunch-reports-keenable-raises-26-million-to-build-web-search-for-ai-agents); [securitylab.ru](https://www.securitylab.ru/news/576520.php)
- **Access surface (vendor):** REST API, MCP server, CLI with the same key; agent skill file published at keenable.ai/SKILL.md — [keenable.ai/SKILL.md](https://keenable.ai/SKILL.md); third-party integration page in Gradium docs — [docs.gradium.ai](https://docs.gradium.ai/integrations/web-search/keenable)
- **Absence of user reviews (aggregators, fetched via search 2026-11-05):** SourceForge "Overall 0.0 / 5"; GetApp and Capterra show zero user ratings; ToolJunction lists cons "new entrant", "Web Query Language is still in development", "public pricing and SLA details are limited". — [sourceforge.net](https://sourceforge.net/software/product/Keenable/), [getapp.com](https://www.getapp.com/all-software/a/keenable/), [tooljunction.io](https://www.tooljunction.io/ai-tools/keenable)

### Inferences
- With a 100k/month free allowance (per Parallel's reading) Keenable is the most generous free tier in the field at a time when Brave removed its own; this is likely its early adoption lever rather than benchmark leadership (AA score 67, tied with Parallel Turbo, below Parallel Fast/Advanced).
- All quality numbers are either Keenable-run (NEEDLE, BrowseComp delta) or relayed by a competitor; treat as unverified until AA's own leaderboard page is read directly.

### Gaps
- Zero first-hand practitioner reports located; Reddit/X inaccessible. The AA Search Index page and Keenable's pricing page were not fetched directly.

## Q5. Reproducible community mini-benchmarks (repos with queries and results)

### Takeaway
Yes, but thin: the only genuinely community-authored reproducible artefact found is the pi-search-multi npm package's benchmark report (3 queries x 9 backends, heuristic scoring, 2026-05-04); the substantial open-code harnesses are vendor-run (Perplexity's search_evals, Exa's benchmarks), and the most-cited independent benchmark (AIMultiple) publishes methodology but no repo.

### Cited Findings
- **Community (practitioner) mini-benchmark, 2026-05-04:** pi-search-multi report — queries "latest AI frameworks 2025", "climate change solutions", "python async programming best practices"; 5 results each; 9 backends all 100% success; avg time/quality: Tavily 356 ms/3.7, DuckDuckGo 1158 ms/3.5, Serper 667 ms/3.5, Firecrawl 644 ms/3.5, WebSearchAPI.ai 1323 ms/3.5, Exa 137 ms/3.2, LangSearch 1816 ms/3.2, Marginalia 354 ms/3.0, Brave 460 ms/3.3. Scoring: "keyword relevance (query words matched in title/snippet), source diversity (penalty for generic search engines), and snippet completeness ... normalized to a 0–10 scale." Shipped inside the npm package so it is re-runnable. — [cdn.jsdelivr.net/npm/pi-search-multi@1.0.1/benchmark/benchmark-report.md](https://cdn.jsdelivr.net/npm/pi-search-multi@1.0.1/benchmark/benchmark-report.md)
- **Vendor open-source harness (Perplexity, MIT, 276 stars, 62 forks, 14 commits, fetched 2026-11-05):** "a batteries-included runner for evaluating deep-research systems on challenging web-search benchmarks"; suites BrowseComp 1,266 tasks, DeepSearchQA 900, HLE 2,158 (gated), WideSearch 200; data pulled from Hugging Face, not redistributed. Results (accuracy; WideSearch = f1_by_row): dsqa Perplexity 0.871, OpenAI 0.733, Anthropic 0.815, Exa 0.53, Parallel 0.81; browsecomp 0.805/0.720/0.598/0.38/0.56; hle 0.612/0.614/0.566/0.387/0.515; widesearch 0.651/0.522/0.590/0.471/0.584. — [github.com/perplexityai/search_evals](https://github.com/perplexityai/search_evals). ## Q8. Practitioner comparisons in production: latency, extraction, rate limits, pricing surprises, data retention

### Takeaway
Practitioners consistently report a ~20x latency spread (Brave ~669 ms to Parallel Pro 13.6 s / Perplexity 11+ s), that search APIs return snippets not pages so a second fetch/extract stage is mandatory, and that billing surprises come from credit multipliers (Tavily), per-page billing (Firecrawl), blended token+request billing (Perplexity) and product sprawl (Parallel's six APIs) rather than headline prices.

### Cited Findings
- **Latency spread (practitioner, Gupta, 2026-07-30, citing AIMultiple):** "Latency varies roughly twentyfold across the field, from 669ms to 13.6 seconds." Table: Brave 669 ms, Tavily 998 ms, Exa ~1,200 ms, Firecrawl 1,335 ms, SerpAPI 2,400 ms, Parallel Base ~2,900 ms, Perplexity Sonar 11,000+ ms, Parallel Pro 13,600 ms. — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/); primary numbers [aimultiple.com](https://aimultiple.com/agentic-search)
- **Snippets-not-pages (practitioner, dev.to build996, 2026, undated):** "ranked results with snippets — a few hundred characters each — not pages. An agent that 'searches the web' with only a search API is reasoning over fragments." "Skipping stage two is the root cause of a whole genre of agent failure — confident answers assembled from snippet shards that misrepresent the page." — [dev.to/build996](https://dev.to/build996/tavily-vs-brave-vs-exa-free-search-apis-for-ai-agents-59m1)
- **Pricing surprises (practitioner, Gupta, 2026-07-30):** Tavily credit multipliers (advanced 2x, deep research up to 250 credits); Firecrawl "Billed per page, not per search call"; Perplexity Sonar blended request+token billing "hard to forecast"; Parallel "Six separate APIs, and the Task API alone has nine processor tiers"; You.com Finance Research from $110 per 1,000 calls. — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/)
- **Rate limits (practitioner/vendor):** Brave Answers 2 rps standard (Gupta) — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/); Parallel 600/min Search and Extract, 2,000/min Task (Parallel docs via its article) — [parallel.ai/articles/keenable-vs-parallel.md](https://parallel.ai/articles/keenable-vs-parallel.md); Keenable 10 rps/org (same source); Brave "~1 req/s limit" (pi-search-multi, 2026-05-04) — [pi-search-multi report](https://cdn.jsdelivr.net/npm/pi-search-multi@1.0.1/benchmark/benchmark-report.md); Exa exposes `x-ratelimit-limit`/`x-ratelimit-remaining` headers and 429 with Retry-After (Rhumb) — [dev.to/supertrained](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g)
- **Data retention (practitioner, Gupta, 2026-07-30):** Brave zero data retention only on Enterprise (custom pricing); You.com "SOC 2 certified, zero-data-retention infrastructure"; other vendors not addressed. — [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/). Compliance: Parallel SOC 2 Type 2 + DPA (vendor); Keenable none as of 2026-10-21 (per competitor). — [parallel.ai/articles/keenable-vs-parallel.md](https://parallel.ai/articles/keenable-vs-parallel.md)
- **Serper/SerpApi in agent loops (practitioner, Rhumb, Mar 2026):** Serper 8.0/10 — "For agents that need current events, news, or high-confidence freshness, Serper consistently outperforms neural search options"; weakness "Depends on Google — any Google change or scraping policy enforcement can affect results without notice"; "No semantic/neural mode". — [dev.to/supertrained](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g). Independent (AIMultiple, May 2026): SerpAPI 8th of 8, Agent Score 12.28, "low mean relevant" (3.58/5), latency 2.4 s; pricing Free 250/mo, Developer $75, Production $150, Big Data $275. — [aimultiple.com](https://aimultiple.com/agentic-search)
- **Perplexity as a search API (practitioner, Rhumb, Mar 2026):** 6.8/10 — "Returns synthesis, not raw results — changes the contract". Independent (AIMultiple): 7th of 8, "very high latency", "inconsistent" outside factual verification; $5 per 1,000 requests. — [dev.to/supertrained](https://dev.to/supertrained/exa-vs-tavily-vs-serper-vs-brave-search-for-ai-agents-an-score-comparison-2l1g); [aimultiple.com](https://aimultiple.com/agentic-search)
- **Firecrawl as search (independent, AIMultiple, May 2026):** 2nd of 8, 14.58, latency 1,335 ms, pricing Free/Hobby €14/Standard €74/Growth €298 billed yearly; practitioner (Gupta): "poor fit for simple low-latency lookups where full-page extraction is unnecessary". — [aimultiple.com](https://aimultiple.com/agentic-search); [guptadeepak.com](https://guptadeepak.com/research/web-search-apis-ai-agents-2026/)
- **Brave LLM Context specifics (practitioner, Ledlie, 2026-04-06):** processing overhead "<130ms at p90, yielding total latency <600ms p90"; no JavaScript rendering, no auth handling, "Limited" full-page extraction vs Firecrawl/Bright Data "Yes". — [aledlie.vercel.app](https://aledlie.vercel.app/reports/2026/llm-native-search-evaluation/)
- **Agent-native onboarding (practitioner newsletter, 2026-03-06):** Exa and Tavily "let agents sign up with an email address, get an API key, and run a search in under 5 minutes. No phone verification, no CAPTCHA"; "Every other search API we've rated (Google Custom Search, Bing Search, Algolia) required some combination of phone verification, project creation UI, or manual API key approval." — [buttondown.com/agentnative](https://buttondown.com/agentnative/archive/we-scored-5-search-apis-for-ai-agents-2-were)

### Inferences
- Several "practitioner" write-ups (Gupta, Ledlie) recycle AIMultiple's May 2026 numbers rather than measuring independently; the field has one independent measurement being echoed, not many.
- The strongest cross-source agreement is architectural: search API + separate extraction stage, with vendors differentiating on how much of stage two they bundle and how they bill it.

### Gaps
- Linkup and Jina: no practitioner production reports, latency or pricing data found this wave.
- No practitioner report of a billing dispute or unexpected invoice was located (Reddit/X inaccessible).
