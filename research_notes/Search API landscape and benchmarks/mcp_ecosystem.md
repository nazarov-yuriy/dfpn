Observation date for all live counters (GitHub stars/forks, npm/PyPI downloads, registry listings, PulseMCP visitor estimates): **2026-11-05** unless stated otherwise. GitHub figures come from the public GitHub search API (`api.github.com/search/repositories?q=repo:...`) or the repo page; npm figures from `api.npmjs.org/downloads/point/{last-week,last-month}`; PyPI figures from `pypistats.org/api/packages/<pkg>/recent` (last_month). ## Key Question 1: Official vendor MCP servers (maintainer, hosting, tools, auth, pricing, popularity)

### Takeaway
Every major search/crawl API vendor now ships an official MCP server, and the centre of gravity has moved from local stdio npm packages to **vendor-hosted Streamable-HTTP endpoints** (mcp.exa.ai, mcp.tavily.com, api.perplexity.ai/mcp, mcp.firecrawl.dev, mcp.jina.ai, mcp.kagi.com, mcp.linkup.so, search.parallel.ai, mcp.brightdata.com, mcp.apify.com, mcp.oxylabs.io, mcp.serpapi.com, mcp.zenrows.com, api.you.com/mcp, api.keenable.ai/mcp, mcp.nimbleway.com). Firecrawl (7.8k stars, ~535k npm downloads/month) and Exa (5.2k stars, ~125k/month) lead on GitHub/npm; Apify's server has the most stars of any (14.8k) but is a scraping marketplace rather than a pure search server. A growing minority (Exa, Firecrawl, Parallel, Jina, You.com, Keenable, Tavily) allow **keyless/anonymous** use at a rate limit, and most now also support **OAuth** sign-in so the server bills a team account rather than a pasted key.

## Key Question 4: How the big agent platforms expose search without MCP (defaults and built-in pricing)

### Takeaway
Each frontier vendor sells a first-party server-side search tool at a flat per-call fee, and their own agents default to it: Anthropic web search $10/1k searches (web fetch free) and Claude Code's `WebSearch` uses that backend with a 200-call session cap; OpenAI $10/1k calls on GPT-5/reasoning models ($25/1k preview on GPT-4o/4.1) and Codex defaults to a `cached` OpenAI-maintained index; Google $14/1k after 5,000 free/month on Gemini 3 ($35/1k on 2.5) and Gemini CLI ships `google_web_search`; xAI $5/1k web-search calls. Among IDE agents, Zed restricts `search_web` to Zed Pro subscribers, Windsurf's Cascade is now legacy under Devin, and Cursor's @Web is widely reported (but not first-party-confirmed) to run on Exa.

### Cited Findings
- **Anthropic API**: web search tool versions `web_search_20250305` (basic), `web_search_20260209` (dynamic filtering via code execution), `web_search_20260318` (`response_inclusion`); params `max_uses`, `allowed_domains`/`blocked_domains` (not both), `user_location`; results carry `encrypted_content` that must be echoed back, citations always on; **"$10 USD per 1,000 searches, plus standard token costs"**, errors not billed; "Simple factual queries typically use 1–3 searches; comparative or multientity research can use 10 or more"; org admins can disable or domain-restrict in Console — [Anthropic web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool). Third-party pages still quote the older Live Search rate of $25 per 1,000 sources ($0.025/source) — [feedbagel](https://feedbagel.com/post/xai-grok-model-pricing-and-tool-costs-documentation); the official pricing page fetched no longer lists it.
- **Zed**: built-in `search_web` "only available to Zed Pro subscribers using the Zed provider"; BYOK users are told to connect an MCP server; `fetch` tool returns Markdown — [Zed AI tools](https://zed.dev/docs/ai/tools).
- **Windsurf**: `docs.windsurf.com/windsurf/cascade/web-search` now redirects to Devin docs where "Cascade is the legacy agent in Devin Desktop" and "Devin Desktop no longer starts new Cascade conversations"; the page no longer documents web search — [Devin docs (Cascade)](https://docs.devin.ai/desktop/cascade/web-search).
- **Cursor**: official @Web docs say Agent "will automatically search the web when it needs up-to-date information" without naming a backend — [Cursor @Web](https://docs.cursor.com/context/%40-symbols/%40-web); third-party profiles state Cursor's in-product web search "runs on Exa" / Exa is Cursor's "default web-search backend" — [geo.sig.ai](https://geo.sig.ai/compare/exa-vs-cursor), [contextbolt](https://contextbolt.com/tools/mcp-server-directory/exa/). Exa also ships an official Cursor plugin (10 stars) — [exa-labs/exa-cursor-plugin](https://github.com/exa-labs/exa-cursor-plugin).
- **Cline / Continue / Roo / OpenCode / Kiro / Amp etc.**: Parallel's and Firecrawl's client lists name Cline, Continue.dev, Roo Code, OpenCode, Kiro, Amp, Goose, Warp, Raycast and LM Studio as MCP-capable targets — [Parallel Search MCP](https://docs.parallel.ai/integrations/mcp/search-mcp); [firecrawl/cli](https://github.com/firecrawl/cli). Tavily's tutorial covers Cline in VS Code — [tavily-ai/tavily-mcp](https://github.com/tavily-ai/tavily-mcp).

### Inferences
- Flat per-call pricing has converged to $5–$14 per 1,000 for first-party tools (xAI $5, Anthropic/OpenAI $10, Google $14), the same band as vendor APIs (Brave $5, Perplexity $5, Exa $4–7, Keenable $4, Linkup ~$5–6, Kagi $12), so MCP vendors compete on result format, filters, fetch bundling and free tiers rather than headline price.
- Anthropic making web fetch free while charging for search mirrors the vendor pattern (Tavily/Keenable price fetch at or below search), reinforcing the "search then fetch" two-step as the standard agent loop.
- Codex's `cached` default (no external web access) and Zed's Pro-only gate create demand for third-party MCP search in exactly those clients, which is why Keenable, Parallel and Exa publish Codex-specific setup.

### Gaps
- No first-party Cursor statement confirming the Exa backend was found (WebSearch budget exhausted before this could be pursued further).
- Cline's and Continue's current built-in web-search status and Perplexity Comet's tool exposure were not verified from primary docs.
- Whether xAI's legacy per-source Live Search billing is formally deprecated, and its date, could not be confirmed from the official page.
- ChatGPT consumer web search backend (historically Bing) was not researched here.

## Key Question 5: Agent skills and non-MCP alternatives (SKILL.md, Agent Skills standard, OpenAI apps, CLI-first)

### Takeaway
Search vendors are now shipping three parallel surfaces: hosted MCP, an Agent-Skills `SKILL.md` package, and an agent-oriented CLI. Anthropic's Agent Skills format (open-sourced 2025-12-18, donated to the Linux Foundation's AAIF per an Oct 2026 report) is the packaging layer; Keenable (`brew install keenableai/tap/keenable-cli`, SKILL.md at app.keenable.ai), Firecrawl (`firecrawl-cli`, 677 stars, `npx skills add firecrawl/skills`), Brave (`bx`), Nimble (13 skills), You.com (agent-skills repo) and Parallel (`parallel-cli`) all follow it.

### Cited Findings
- **Agent Skills standard**: skills released for Claude in October 2025, specification published as an open standard on 2025-12-18 with SKILL.md (YAML frontmatter + Markdown) — [Strapi](https://strapi.io/blog/what-are-agent-skills-and-how-to-use-them); adoption claims range from "26+ platforms including Claude, OpenAI Codex, Gemini CLI, GitHub Copilot, Cursor, and VS Code" to "more than 70 agent platforms", with Anthropic-reported "1 million skills… nearly 280 million installed" — [The New Stack](https://thenewstack.io/?p=22810509); a 2026-10-22 report says Anthropic is donating Agent Skills, the name, GitHub org and agentskills.io to the Agentic AI Foundation under the Linux Foundation (single-sourced) — [FourWeekMBA](https://fourweekmba.com/ai-anthropic-donates-agent-skills-after-nearly-280m-installs/). The official MCP registry even lists an MCP server for searching the skills.sh skills registry (`ai.com.mcp/skills-search`) — [registry](https://registry.modelcontextprotocol.io/v0/servers?search=search).

## Key Question 6: Patterns (search + fetch pairing, deep research, LLM-optimized formats, keyless/freemium growth)

### Takeaway
Across vendors the de facto MCP search surface is a four-tool pattern: search (ranked results with excerpts, often markdown) → fetch/extract (clean markdown of a known URL) → map/crawl (site discovery) → async "research/agent" (minutes-long, structured output). LLM-oriented formats (markdown, token budgets, relevance-ranked excerpts, `llm_context`-style grounding endpoints) are now explicit product features, and keyless or OAuth-first tiers have become the standard acquisition funnel, including micropayment (x402) experiments.

### Cited Findings
- **Search + fetch pairing**: Anthropic documents "Combined search and fetch" where web search locates and web fetch retrieves, with fetch free and restricted to in-context URLs — [Anthropic web fetch](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool); Claude Code's WebSearch "doesn't fetch the result pages… it follows up with WebFetch" — [Claude Code tools](https://code.claude.com/docs/en/tools). Vendor pairs: Exa `web_search_exa`/`web_fetch_exa` — [Exa](https://exa.ai/docs/reference/exa-mcp); Keenable `search_web_pages`/`fetch_page_content` — [Keenable](https://docs.keenable.ai/mcp-server.md); Parallel `web_search`/`web_fetch` — [Parallel](https://docs.parallel.ai/integrations/mcp/search-mcp); Linkup `linkup-search`/`linkup-fetch` — [Linkup](https://docs.linkup.so/pages/integrations/mcp/mcp); Kagi `kagi_search_fetch`/`kagi_extract` — [Kagi](https://github.com/kagisearch/kagimcp); Tavily `tavily_search`/`tavily_extract` — [Tavily](https://docs.tavily.com/documentation/mcp); DuckDuckGo `search`/`fetch_content` — [DDG](https://github.com/nickclyde/duckduckgo-mcp-server); SearXNG `searxng_web_search`/`web_url_read` — [SearXNG](https://github.com/ihor-sokoliuk/mcp-searxng); Kindly `web_search` already returns `page_content` markdown — [Kindly](https://github.com/Shelpuk-AI-Technology-Consulting/kindly-web-search-mcp-server).
- **Deep-research tools**: Tavily `tavily_research` ("multi-source research… detailed answer", 15–250 credits at `model=pro`) — [Tavily](https://docs.tavily.com/documentation/mcp), [credits](https://docs.tavily.com/documentation/api-credits); Exa `agent_run` (multi-step research, `outputSchema`, `effort`, resumable `runId`; $0.012–$1.00/request) — [Exa](https://exa.ai/docs/reference/exa-mcp), [pricing](https://exa.ai/pricing); Perplexity `perplexity_research` (Agent API `high`) — [Perplexity](https://docs.perplexity.ai/guides/mcp-server); Linkup async `linkup-research` + `linkup-get-research` polling ($0.25–2.50) — [Linkup](https://docs.linkup.so/pages/integrations/mcp/mcp), [pricing](https://www.linkup.so/pricing); Firecrawl `firecrawl_agent`/`firecrawl_agent_status` with `maxCredits` default 2,500 — [Firecrawl](https://github.com/firecrawl/firecrawl-mcp-server); Parallel `task-mcp` "for deep research or task groups" — [registry](https://registry.modelcontextprotocol.io/v0/servers?search=ai.parallel); Omnisearch groups these as `ai_search` (Exa Answer, Linkup, Tavily Research) — [omnisearch](https://github.com/spences10/mcp-omnisearch).
- **LLM-optimized result formats**: Brave `brave_llm_context` "pre-extracted web content for LLM grounding and RAG, with token and snippet limits" and `bx context` "token-budgeted content" — [Brave MCP](https://github.com/brave/brave-search-mcp-server), [bx](https://github.com/brave/brave-search-cli); Keenable `snippet_max_length` 180–10,000 and `max_chars` on fetch — [Keenable](https://docs.keenable.ai/mcp-server.md); Jina `read_url` with `question`, `chunk_size`, `topk`, and server-side `max_tokens` — [Jina](https://github.com/jina-ai/MCP); SerpApi `output: "md"` and `mode: compact` — [SerpApi](https://github.com/serpapi/serpapi-mcp); Parallel's `web_search` requires an `objective` plus 3–6-word `search_queries` and `web_fetch` returns "complete page markdown" only when `full_content: true` — [Parallel](https://docs.parallel.ai/integrations/mcp/search-mcp); Anthropic's dynamic filtering lets Claude "write and run code that filters the search results before they reach the context window" — [Anthropic web search](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool); Google's `google_web_search` returns a pre-synthesized summary rather than raw results — [Gemini CLI](https://geminicli.com/docs/tools/web-search/). Tool-count discipline is also a theme: Exa's `?tools=` allowlist, Jina's `include_tags`, Bright Data's `groups`, Firecrawl's `/mcp-search` 9-tool variant (KQ1).
- **Keyless / freemium funnels**: Keenable 1,000 req/h/IP keyless, 100K/month free with login, x402 $0.01/call — [Keenable rate limits](https://docs.keenable.ai/rate-limits.md), [pricing](https://keenable.ai/pricing); Parallel "Anonymous use on /mcp is free and requires no key" — [Parallel](https://docs.parallel.ai/integrations/mcp/search-mcp); Exa keyless search/fetch with IPv4-only enforcement and $10 monthly-resetting credit — [Exa](https://exa.ai/docs/reference/exa-mcp), [pricing](https://exa.ai/pricing); Firecrawl keyless scrape/search/parse plus 1,000 free credits/month — [Firecrawl](https://github.com/firecrawl/firecrawl-mcp-server), [pricing](https://www.firecrawl.dev/pricing); Tavily keyless Search/Extract plus 1,000 credits/month — [Tavily](https://docs.tavily.com/documentation/mcp), [credits](https://docs.tavily.com/documentation/api-credits); You.com `?profile=free` "no API key, no signup" — [You.com](https://github.com/youdotcom-oss/mcp); Jina free 10M tokens — [Jina](https://jina.ai/reader); Bright Data 5,000 requests/month free — [Bright Data](https://github.com/brightdata/brightdata-mcp); Brave $5/month free credit per plan — [Brave](https://brave.com/search/api/); Linkup 4,000 free queries — [Linkup](https://www.linkup.so/pricing); ZenRows auto-created Free account with 5,000 credits/month — [ZenRows](https://github.com/ZenRows/zenrows-mcp). Several registry entrants bill per call in USDC over x402 (`ai.clawfetch/mcp`, `com.fetchdelta/agent-tools`, `cloud.fetcher/fetcher`) — [registry](https://registry.modelcontextprotocol.io/v0/servers?search=fetch).
- **OAuth as the hosted-MCP auth default**: Perplexity ("Sign in with Perplexity", OAuth 2.1 PKCE), Tavily, Exa (`?login`), Firecrawl (`/mcp-oauth`), Parallel (`/mcp-oauth`), Keenable (`/mcp-oauth`), Apify, ZenRows and Nimble's Claude plugin all offer OAuth; Kagi and Oxylabs say OAuth is not yet supported/"on the roadmap" (KQ1 sources).
- **Vendor instructions to disable competing tools**: Keenable tells users to "disable any built-in or third-party search/fetch tools (WebSearch, WebFetch, brave_search, tavily_search…)" because "leaving both active causes agents to pick inconsistently", and its Codex setup sets `web_search = "disabled"` — [Keenable](https://docs.keenable.ai/mcp-server.md).

### Inferences
- Because the first-party search tools of Anthropic/OpenAI/Google are on by default (or one flag away), third-party MCP search vendors must either out-compete on result quality/format or capture clients where first-party search is absent or gated (Codex `cached` default, Zed Pro-only, Bedrock-hosted Claude Code).
- The industry is standardising a "search returns excerpts, fetch returns markdown, research returns a synthesized answer" contract; this makes servers largely interchangeable at the tool-name level, which is exactly what aggregators (omnisearch, Kindly, OpenSERP, search-cli) exploit.
- Keyless tiers plus OAuth suggest the pasted-API-key model is being deprecated for agent use; usage attribution is shifting to IP (keyless), org (OAuth), or wallet (x402).

### Gaps
- No vendor publishes keyless-tier conversion or usage statistics; the growth-strategy claim rests on product design, not disclosed metrics.
- Hacker News discussion threads on keyless MCPs/Keenable could not be retrieved (search budget exhausted).
- Result-quality benchmarks comparing these MCP tools are outside this note's scope (covered elsewhere in this research set).
