### Learning path for this layer (ordered by how many vendors ask for it)
1. **Python + one systems language (Rust first, C++ second).** Rust is named by Exa, Perplexity, Keenable, Linkup, Tavily and Brave; C++ by Exa, Perplexity, Tavily, Brave. Read tantivy, then Stract's crawler and indexer; port one PISA algorithm to Rust.
2. **Kubernetes + Terraform on AWS or GCP**, with stateful workloads (search shards, crawl fleets, queues). Named by Perplexity, Tavily, Firecrawl, Linkup, Parallel.
3. **Spark over a lakehouse (Parquet/Delta/Iceberg) + object storage**, then Lance and Ray Data. Named by Exa, Linkup, Perplexity (Databricks/Snowflake), Tavily (Snowflake/Databricks). Start with commoncrawl/cc-pyspark.
4. **Crawler engineering**: StormCrawler or Nutch, robots.txt, per-domain queues, prioritisation. Named by Exa, Keenable, Perplexity, Linkup, Firecrawl.
5. **Headless Chromium and anti-bot**: Playwright/CDP, TLS fingerprints (JA3/JA4), custom Chromium builds. Named by Tavily, Exa, Firecrawl, Jina (reader).
6. **Inverted index + hybrid retrieval in Vespa** (the one engine two vendors used), with Anserini/PISA for fundamentals and FAISS/usearch/Qdrant for ANN.
7. **Ranking cascades**: GBDT LTR (LightGBM/CatBoost), cross-encoders, ColBERT; evaluation with nDCG and the vendors' open harnesses (needle, search_evals).
8. **Embedding-model training in PyTorch** (contrastive learning, FSDP), then **GPU inference** (vLLM, Triton, TEI; read pplx-garden for the Rust/RDMA frontier).
9. **TypeScript** for MCP servers, SDKs and dashboards (every vendor's public repos).
