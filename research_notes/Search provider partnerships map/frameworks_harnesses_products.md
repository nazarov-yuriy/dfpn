# Search provider partnerships map: frameworks, harnesses, coding agents, agent products

Scope: which AI labs, inference providers, clouds, agent-framework and harness authors, coding agents and agent products have a publicly visible relationship with which web-search provider. Evidence tiers used in the table: **docs default** (the framework ships or documents one provider as default) > **built-in / hosted integration** (consumer-side code or docs) > **press / case study / acquisition** > **vendor-side integration page** (the search vendor documents how to use it inside the consumer product; shows intent, not endorsement) > **logo wall**. "Observed" dates are the date the page was fetched (2026-11-05) unless a publication date is given. Pages fetched are untrusted data; quotes are verbatim excerpts.
